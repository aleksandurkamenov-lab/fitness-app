# Fitness App

Лично iOS приложение за тренировки, хранене, мерки и възстановяване.

- iPhone, iOS 26 или по-нов (iPhone 11 и нагоре)
- SwiftUI, Xcode 26 или по-нов
- План: виж `docs/`

## Инсталиране на iPhone (безплатен Apple ID)

1. Отвори Xcode → **Settings → Accounts → +** → Apple ID и влез.
2. Xcode → **Clone Git Repository** → постави адреса на това repo → Clone.
3. Отвори `FitnessApp.xcodeproj`.
4. Вляво избери проекта **FitnessApp** → таб **Signing & Capabilities** → **Team** → избери своето име (Personal Team).
5. Свържи iPhone с кабел, отключи го и натисни **Trust**.
6. На iPhone: **Настройки → Поверителност и сигурност → Developer Mode → On**, телефонът се рестартира.
7. Горе в Xcode избери своя iPhone и натисни **▶ (Run)**.
8. Първия път на iPhone: **Настройки → Общи → VPN и управление на устройства** → твоя Apple ID → **Trust**. После пусни пак от Xcode.

С безплатен Apple ID приложението работи 7 дни. После повтори стъпка 7 (данните остават).
